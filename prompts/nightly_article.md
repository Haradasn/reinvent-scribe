# 夜の記事化プロンプト(Claude に渡す)

録音一覧の「記事⤓」で保存した zip を展開し、`article_source.md` と `photos/` の写真を、以下と一緒に Claude に渡す。

---

以下は AWS re:Invent のセッション「[セッションID] [タイトル]」の英語文字起こしです。
これを日本語のブログ記事に仕上げてください。

要件:
- 読んだ人がセッションの内容と重要な点を理解できる、ブログ記事のテイスト
- 冒頭 2〜3 文でセッションの概要と一番のポイント
- 発表された新機能・新サービス・具体的な数字は漏らさず、正確に
- AWS サービス名の誤認識(音の似た別単語)があれば文脈から正しい名前に直す
- 見出しを使って読みやすく。長さは内容に応じて 1,000〜2,000 字程度
- 写真は内容に合う位置に `![説明](photos/ファイル名)` で入れる。スライドの文字と発言が食い違う時はスライドの数値を優先し、その旨を書く
- 「スライド写真の読み取り」は発言ではない。発言のように書かない
- 最後に「自分たちの業務にどう活きるか」の示唆を 2〜3 行
