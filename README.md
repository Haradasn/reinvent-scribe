# reinvent-scribe

re:Invent などの英語セッションをローカルで録音しながらリアルタイムで文字起こしし、
準リアルタイムの日本語要約、文字起こしチャット、出張日報(Slack 貼り付け用)までを1つで扱うローカル Web アプリ。

- 文字起こしはローカル (faster-whisper) で行うので、会場の Wi-Fi が使えなくても録音と字幕は動く
- 停止後にバックグラウンドで高精度モデルによる再文字起こし (`transcript_hq.md`)
- 要約/チャット/日報は OpenAI 互換の LLM API(安いモデルを自由に選択、未設定でも機能を減らして動く)

## はじめかた

用意するものは Chrome と Python 3.11 以上です([ダウンロード](https://www.python.org/downloads/))。Windows では、Python のインストールの最初の画面で「Add python.exe to PATH」にチェックを入れます。

1. このページの緑の「Code」ボタンを押し、「Download ZIP」で保存して展開する(git が使えるなら clone でも可)
2. フォルダの中の起動ファイルをダブルクリックする
   - Mac: `start-mac.command`
   - Windows: `start-windows.bat`
3. 初回は準備に数分〜数十分かかり、終わるとブラウザが開く
4. 開いた「はじめの設定」を上から順に進める(1と2だけで録音と英語字幕は使えます)

起動中に出る黒い画面は閉じないでください。次回からも同じファイルをダブルクリックするだけです。

<details><summary>起動できない時</summary>

- Mac で「開発元を確認できません」と出る: システム設定 → プライバシーとセキュリティ →「このまま開く」
- Mac で権限エラーが出る: ターミナルで `chmod +x ` に続けて `start-mac.command` をドラッグし、Enter
- Windows で「PC が保護されました」と出る: 「詳細情報」→「実行」(社用 PC では管理者の制限で動かないことがあります)
- マイクが使えない: OS の設定で、ターミナル(Windows はデスクトップ アプリ)のマイクを許可して起動し直す

</details>

> **出発前に必ず**、設定の2(モデルのダウンロード)と、録音 → 停止まで一度試してください。
> 会場のネットではダウンロードが間に合わないことがあります。

### 設定の変更

画面右上の「設定」から、いつでも変更できます。キーはこのフォルダの `.env` にだけ保存され、Git には入りません。

| 項目 | 必要? | できること |
|---|---|---|
| 1 マイク / 2 モデル | 必須 | 録音・英語字幕(ネット不要) |
| 3 OpenAI | おすすめ | 日本語訳・要約・チャット・日報・Web 検索・写真の読み取り |
| 4 AssemblyAI | 任意 | 速く正確な字幕 |
| 5 Chrome 拡張 | おすすめ | 自分の re:Invent の予定と概要の取り込み |
| 6 Gmail | 任意 | 日報・要約をメールで送る |

料金の目安(2026年11月): OpenAI は 1 時間 約$0.03〜、AssemblyAI は 1 時間 約$0.30。使う前に各社の最新の料金を確認してください。

<details><summary>細かい設定(.env を直接編集)</summary>

`SUMMARY_INTERVAL_SEC`(要約の間隔・秒、既定180)、`LLM_FALLBACK_MODELS`(混雑時に試すモデル、カンマ区切り)、
`ASSEMBLYAI_MODEL`(字幕のモデル、既定 assemblyai-stt-3-7-realtime)、`EVENT_TZ`(既定 America/Los_Angeles)、`DATA_DIR`(保存先)、`WHISPER_MODEL`(字幕用モデル)

</details>

### 録音と共有

録音・撮影の可否はイベントと登壇者のルールに従ってください。オンラインの機能を使うと、音声や文字起こしが各サービスに送られます。

## 使い方

1. セッション前: `sessions.csv` を用意しておくと 1 クリックで開始できる(下記)
2. セッション中: 左の予定を選んで ● を押すと録音開始(予定外は「＋ 予定外の録音」)。英語字幕が流れ、
   オンラインなら数分ごとに日本語要約が右ペインに積まれる。
   チャット欄で「さっきの新機能って何?」のように質問も可能
   右側の「メモ」タブには、録音ごとのメモを自由に書ける(書くと自動で保存)。
   字幕の「メモへ」で発言を時刻付きで引用でき、引用の行からその字幕に戻れる。
   メモは日報の所感、チャット、記事用データにも使われる
3. 停止後: 高精度文字起こしが自動で始まり、`transcript_hq.md` ができる。オンラインなら、続けてその全文から日本語要約を作り直す(オフラインの時は録音中の要約が残る)
4. 夜: `transcript_hq.md` を Claude に渡して記事にする(`prompts/nightly_article.md` 参照)
5. 1日の終わり: 「日報」→「日報を作成」でできた日報をコピーし、Slack に貼って上司へ共有

## sessions.csv(予定から1クリックで録音)

リポジトリ直下に置きます(個人の予定なので Git には入りません)。文字コードは UTF-8 で、1行目は次の見出しにします。

```csv
date,start,end,id,title,venue,kind
2026-12-01,08:30,10:45,KEY001,Opening Keynote,Venetian,reserved
```

- 時刻は現地時間(既定 `EVENT_TZ=America/Los_Angeles`)。PC の時刻設定には影響されません
- `id` は空でよい(曜日+開始時刻になります)。`kind` は reserved / favorite / personal
- カンマを含む項目は `"` で囲む。保存後30秒以内に画面へ反映されます
- 予定日以外は「試し録り」になり、予定は録音済みになりません

### 「予定を更新」ボタン(Chrome 拡張)

導入は「設定」の5を見てください。re:Invent サイトにログイン済みの Chrome で押すと、予定と概要を取り込みます。
拡張機能が押すのは日付と予定カードだけで、予約は変更しません。以前の予定は `sessions.csv.bak` に残ります。
re:Invent 側の画面が変わると読めなくなることがあります。

## スライド写真

「写真を取り込む」に、スマホの写真(HEIC / JPEG / PNG)をまとめてドロップします。撮影時刻から録音に振り分け、
確認して保存すると、録音を開いた時に字幕の間へ並びます。

- iPhone から Mac へは AirDrop が簡単です。共有画面の「オプション」で「すべての写真データ」をオンにすると撮影情報が残ります
- 元の写真はそのまま保存。表示・AI・メール・記事用の JPEG は位置情報などを除いたものです
- AI での読み取りとメール添付は押した・選んだ写真だけ。撮影や共有が禁止のスライドに注意
- 録音の「記事用データをダウンロード」で文字起こし・要約・写真をまとめた zip を保存し、Claude に渡せます

## glossary.txt の書き方

字幕で聞き間違えやすい製品名や登壇者名を、`glossary.txt` に1行に1つ書きます。`#` で始まる行は読みません。
書いた語は Whisper(ネット不要の字幕)と AssemblyAI の両方で使い、次の録音から反映します。

自分だけの用語は `glossary.mine.txt` に同じ形で書きます。このファイルは Git に入らず、`glossary.txt` より先に読みます。

- 自分が聞くセッションの製品名・登壇者名に合わせて書き換えてください
- AssemblyAI へ送るのは先頭から100個までで、51文字以上の語は送りません。Whisper で使うのは約170語までです
- `AWS` のように普通に聞き取れる語や一般的な英単語は、入れない方が別の語を誤ってその語に書き換えることが減ります

## データの場所

```
data/2026-12-01/1201_0830_KEY001/
  audio.wav          # 録音(クラッシュしても途中まで有効)
  transcript.md      # リアルタイム文字起こし
  transcript_hq.md   # 高精度版(夜に Claude へ渡すのはこちら)
  meta.json          # ID/タイトル/メモ/開始終了時刻
  chat.md            # チャット履歴
data/2026-12-01/daily_summary.md   # 出張日報
```

